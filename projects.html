Card Viewer

Quickly see what's on an SD card without waiting for every thumbnail to be fully rendered. Card Viewer uses previews embedded in camera photos to show images early, then refines the thumbnails in the background. Supports HIF, HEIC, and HEIF files alongside common image formats.

  • Embedded previews and priority loading for photos on screen let you start browsing right away.
  • A persistent thumbnail cache speeds up return visits.
  • Select photos and export them to a ZIP with their matching RAW files.
  • C#
  • .NET 10
  • WPF
  • MVVM
